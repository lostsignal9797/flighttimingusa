Flight Time FAQ

What is flight time?

Flight time is an estimated duration of air travel between two locations. It does not include airport check-in, security or baggage time.

Are these exact flight times?

No. This preview uses modeled estimates. Actual flight duration varies by aircraft, routing, winds, air traffic and operations.
